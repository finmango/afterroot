# AfterRoot — AI-Powered Disaster Financial Recovery

**By [FinMango](https://finmango.org) · 501(c)(3)**

AfterRoot helps disaster survivors navigate the maze of federal, state, and nonprofit aid programs. One conversation, every program you qualify for.

## Live Tools

- **[Disaster Aid Finder](disaster-aid-finder.html)** — 8-question intake → personalized list of every program you may qualify for (FEMA, SBA, Medicaid, crisis counseling, food assistance, and more)
- **[Recovery Roadmap](recovery-roadmap.html)** — Interactive timeline showing the exact filing sequence, dependency chain, and deadlines

## About

Built by FinMango for the [Google.org Impact Challenge: AI for Government Innovation](https://www.google.org/impact-challenges/ai-government-innovation/).

AfterRoot sits at the intersection of Health, Resilience, and Economy — because when disaster hits, they're the same problem.
